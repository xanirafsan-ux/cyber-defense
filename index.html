  1. Validate authentication, device, IP, and transaction logs.

  3. Set initial severity based on impact.
  4. Escalate to L2 Security and Fraud within SLA.
  5. Use only an authorized protection playbook.
  6. Preserve evidence and document timestamps.

Tool awareness

How the security stack fits together

These are learning-level explanations. They should be updated with your real lab screenshots and notes as you gain practice.

SIEM

Aggregates and correlates logs so an analyst can investigate events across identity, network, endpoint, and application sources.

SOAR

Automates repeatable response actions and playbooks while keeping approvals and evidence visible.

EDR

Provides endpoint telemetry and response controls for suspicious processes, files, persistence, and host activity.

PAM / DAM

Monitors privileged access and database activity, helping detect misuse and enforce accountability.

Firewall / WAF

Controls network or web traffic and provides useful signals for blocked requests, scanning, abuse, and exploitation attempts.

False-positive tuning

Uses analyst feedback and trusted context to improve rules without hiding real threats.
